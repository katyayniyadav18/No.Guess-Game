🎯 Number Guessing Game

A simple Python Number Guessing Game created to practice fundamental Python concepts such as variables, random numbers, user input, conditional statements, loops, and break statements.

📌 About the Project

In this game, the computer randomly selects a secret number between 1 and 20. The player has to guess the number.

After every guess, the program gives a hint:

- Too low → The guessed number is smaller than the secret number.
- Too high → The guessed number is larger than the secret number.
- Correct! → The player has guessed the right number.

The game continues until the correct number is guessed.

▶️ How to Run

1. Clone the repository

git clone https://github.com/katyayniyadav18/No.Guess-game.git

2. Open the project folder

cd Number-Guessing-Game

3. Run the Python file

python guessing_game.py

🎮 How to Play

1. Run the program.
2. Enter a number between 1 and 20.
3. Follow the hints given by the program.
4. Keep guessing until you find the secret number.
5. The game ends when you guess correctly.
